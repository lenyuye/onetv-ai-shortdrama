# onetv-ai-shortdrama-
Open-source local-first AI short-drama studio — LibTV / 即梦 style workflow: Agent chat, node canvas, script→storyboard→image/video generation, TTS, FFmpeg timeline render. BYO OpenAI-compatible API, ComfyUI &amp; Ollama local models, Keychain-secured keys, no telemetry. Tauri 2 + React + Rust.
