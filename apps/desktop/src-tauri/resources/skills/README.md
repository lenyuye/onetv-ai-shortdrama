# skills/ — 内置 Skill 包

Skill = 工作流模板 + 提示词 + Schema，声明权限、不能静默改 Provider/白名单/导出路径。

| 包 | 用途 |
| --- | --- |
| short-drama | 一句话 → Story Bible → 分集剧本（都市情感短剧导演） |
| storyboard | 剧本 → 镜头表 → 分镜图组 |
| video-recreation | 本地视频 → 结构化镜头 JSON → 复刻计划 |
| tvc | 产品 TVC/展示片工作流 |

安装方式（Phase 9 实现 Hub UI）：本地文件夹拖入，或 Git URL + tag 锁定。
